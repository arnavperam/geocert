# Common-grid clarification

The frozen plan preserves the eight-budget primary analysis and uses a finer 17-budget grid for the width study. To avoid confounding a changed ribbon width with more opportunities to detect a marginal-bound difference, the unchanged baseline spectra are additionally projected onto that same 17-budget grid. Singleton costs are reconstructed to evaluate the marginal bounds at each new grid point. Every original row is checked for exact agreement, and the original CSV files are preserved.

This is a deterministic projection of already computed baseline spectra, not a new uncertainty family, selected gene set, or optimized budget grid. The manuscript keeps 4/46 and 203/1,026 attached to the original eight-budget analysis. The reach-study table uses the common finer grid for every family. This clarification was recorded before computing that additional baseline projection; it does not retroactively change the frozen width-selection protocol.
